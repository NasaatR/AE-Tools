Close After Effects and run **AE-Tools-1.1-Setup.exe**. Restart AE and open **Window → Extensions → AE Tools**. The installer targets the current Windows user. The signed ZXP is an alternative for an existing ZXP installer; choose one installation route.

Two new one-click text tools cover four entry/exit direction and order combinations. Native Lines and Words grouping, 24 px travel, 30-frame initial duration, 10% stagger, editable per-layer travel and marker retiming. The original Marker text reveal is also available. Working scope and limitations are in the README. The ZXP uses a self-signed preview certificate, the EXE has no Windows publisher signature, and a real After Effects acceptance run is pending.
