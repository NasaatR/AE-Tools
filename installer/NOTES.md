Close After Effects and run **AE-Tools-1.0-Setup.exe**. Restart AE and open **Window → Extensions → AE Tools**. The installer targets the current Windows user. The signed ZXP is an alternative for an existing ZXP installer; choose one installation route.

Eleven registered commands, a searchable customizable panel and a marker-driven text reveal. Working scope and limitations are in the README. The ZXP uses a self-signed preview certificate, the EXE has no Windows publisher signature, and a real After Effects acceptance run is pending.
